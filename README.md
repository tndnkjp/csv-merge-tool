# CSVMerge - 複数CSVの一括結合・出力マクロ

フォルダ内に散らばった複数のCSVファイルを、ワンクリックで1つに結合するExcel VBAツールです。
「毎回手でコピペして集計している」「月末に部署ごとのCSVを1枚にまとめる作業がある」といった定型作業の自動化を想定しています。

## ダウンロード

**[⬇️ CSVMerge.xlsm をダウンロード](https://github.com/tndnkjp/csv-merge-tool/raw/main/CSVMerge.xlsm)**

上のリンクをクリックするだけで、ブラウザが自動的にファイルをダウンロードします（gitの知識は不要です）。

## できること

- 指定フォルダ内のすべての `.csv` を自動検出
- 1行目をヘッダーとして認識し、2ファイル目以降のヘッダー行は自動でスキップ
- 結合結果をExcelシート（`結合結果`シート）に書き出し
- 結合結果を新しいCSVファイルとしても出力
- 文字コードの設定間違いによる文字化けを自動検知し、`ログ`シートに警告（元の行データ付き）
- ワンクリックで`結合結果`・`ログ`シートを削除してリセット

## 使い方

1. **[`CSVMerge.xlsm` をダウンロード](https://github.com/tndnkjp/csv-merge-tool/raw/main/CSVMerge.xlsm)して開く**
2. 黄色いセキュリティバーが出たら「コンテンツの有効化」をクリック
   （出ない場合は下記FAQ参照）
3. 「**CSVを結合する**」ボタンをクリック
4. フォルダ選択ダイアログで、結合したいCSVが入っているフォルダを指定
5. 確認メッセージで「はい」を押すと結合開始。完了すると `結合結果` シートに全件が表示される

結合結果をリセットしたい場合は、「**結果シート削除**」ボタンを押してください。

これだけで使えます。VBAエディタを開く必要はありません。

## つまずきやすいポイント（FAQ）

### 「セキュリティの警告」「マクロが無効にされました」と出る

Excelの初期設定では、インターネット経由で取得したファイルのマクロは既定でブロックされます。

- ファイルを右クリック → `プロパティ` → 下部の「許可する」にチェック → OK
- それでも警告が出る場合：`ファイル` → `オプション` → `セキュリティセンター` → `セキュリティセンターの設定` → `マクロの設定` で「警告を表示してすべてのマクロを無効にする」になっているか確認し、実行時に「コンテンツの有効化」を選択

`結合結果` シートの文字が読めない記号になっていたり、列の内容がズレて表示されたりした場合は、文字コードの設定間違いが原因です。あわせて、1行目（ヘッダー）の列数を基準に以降の行の列数が一致しているかを自動チェックしており、ズレを検出すると `ログ` シートにも **【文字化けの疑い】** として警告します（該当行の元データも一緒に記録されるので、欠けた値もそこから確認できます）。対処は「カスタマイズしたい場合」をご覧ください。

### 日付や数値が変わってしまう（例: "001" が "1" になる、日付がずれる）

これは本ツール固有の問題ではなく、Excelがセルに値を書き込む際に自動で型変換を行うために起こります。該当列のみ、結合後に表示形式を「文字列」に変更してください。

### Excelのバージョンによって動作が違う

`ADODB.Stream` と `FileDialog` を使用しており、Windows版Excel 2010以降であれば基本的に動作します。Mac版Excelは `ADODB.Stream` が利用できないため非対応です。

### ヘッダーの列構成がファイルごとに違う

本バージョンは「全ファイルが同じ列構成である」ことを前提にしています。列構成が異なる場合は結合結果がずれ、`ログ`シートに警告が出ます。事前に列を揃えてから実行してください。

## カスタマイズしたい場合

既定の設定を変えたい方向けに、VBAソースコードを `src/modCSVMerge.bas` として同梱しています。

1. `CSVMerge.xlsm` を開き `Alt + F11` でVBEを開く
2. 左側のプロジェクトエクスプローラーで既存の `modCSVMerge` を右クリック →「解放」で削除
3. `ファイル` → `ファイルのインポート` から `src/modCSVMerge.bas` を選び直す
4. 冒頭の「設定セクション」の定数を書き換えて保存

| 定数 | 内容 |
|---|---|
| `INPUT_ENCODING` | 読み込むCSVの文字コード |
| `OUTPUT_ENCODING` | 出力するCSVの文字コード |
| `HAS_HEADER` | 1行目をヘッダーとして扱うか |
| `TARGET_EXTENSION` | 対象拡張子（既定は `csv`） |
| `DELIMITER` | 区切り文字（タブ区切りなら `vbTab`） |
| `OUTPUT_SHEET_NAME` | 結果を書き出すシート名 |
| `LOG_SHEET_NAME` | ログを書き出すシート名 |

> `src/modCSVMerge.bas` はShift-JIS(CP932)で保存されています。テキストエディタで直接編集する場合、UTF-8で上書き保存すると、VBEへの再インポート時に日本語コメントが文字化けするのでご注意ください。

### トラブルシューティング：文字化けする／結合結果の列がズレる

`結合結果` シートの文字が読めない記号になっている、セルの内容がズレている、または `ログ` シートに **【文字化けの疑い】** の警告が出ている場合、ほとんどはCSVの文字コードと `INPUT_ENCODING` の設定が合っていないことが原因です。上記の手順で `src/modCSVMerge.bas` を開き、冒頭の設定セクションにある `INPUT_ENCODING` を変更してください。

> 列数自体がズレていない軽微な文字化け（列数は一致しているが文字だけ読めない記号になっているケース）は、列数チェックでは検知できず `ログ` シートに警告が出ません。`結合結果` シートを目視で確認してください。

```vba
Private Const INPUT_ENCODING As String = "shift-jis"  ' 日本語の古いシステム由来のCSVに多い
Private Const INPUT_ENCODING As String = "utf-8"       ' 最近のWebサービスからのエクスポートに多い
```

迷ったら、対象CSVをメモ帳で開き、「名前を付けて保存」画面の右下に表示される文字コードを確認するのが確実です。
